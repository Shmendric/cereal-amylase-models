# Relationship between the book and computational materials

This repository packaging was prepared on 19 November 2026. It has two clearly identified layers.

1. The public monograph record, DOI **10.5281/zenodo.24378474**, contains `Monografie_Getreideamylasen.pdf` and `Monograph_Cereal_Amylases.pdf`. Its public metadata was checked through the Zenodo record API. The selected metadata and file checksums are recorded under `metadata/`.
2. The calculation files under `research/` are the unchanged research edition 1.0, prepared on 18 November 2026 from manuscript version 36. Their own manifest, file-specific rights assignments, scientific inputs and historical documentation are retained byte for byte. The old Word/PDF files remain inside this baseline because its integrity checks explicitly cover them. For current reading editions, follow the Zenodo record.

No assertion is made that the frozen research PDF, the later typeset German PDF and its English translation are byte-identical editions. This packaging introduces no new scientific result or new experiment. It adds a repository entry point, current citation metadata, project documentation and a new internal reproduction report.

The root citation file points to the actual published record title, which differs from the earlier research title. If the Zenodo title is subsequently corrected, update the root citation and documentation for the next repository version. Do not silently rewrite the frozen baseline or remove its component licences.

The monograph DOI is not assigned to the software. GitHub/Zenodo automatic release archiving has not been configured. If the code is later archived as a separate research object, its own identifier can be linked to the monograph as related material.

Any DNB catalogue link and Amazon edition links can be added when available. Their absence does not prevent reproduction of the calculation files or citation of the Zenodo monograph.
