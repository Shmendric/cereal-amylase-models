# Prepared release 1.0.0

Computational companion to Stefan Traublinger's monograph on kinetic models of enzymatic starch hydrolysis in cereal systems.

- Adds an English project README with a German summary.
- Preserves the complete research edition 1.0 and its file-specific rights assignments unchanged.
- Adds a portable reproduction entry point and repository checksums.
- Adds a CFF 1.2.0 citation pointing to the existing monograph record, DOI 10.5281/zenodo.24378474.
- Records a fresh internal reproduction run, including nominal E/W/P2 optimisation.

This is a repository packaging release. It introduces no new scientific results, experiments or claims of external peer review. The monograph DOI identifies the two PDF editions on Zenodo and does not identify this software snapshot. Component-specific licence conditions remain in force.
